# Notice

henkan is written from public format descriptions and from studying the programs below. They were read to learn what each format holds and what each tool does; no code, text, test, or data table was copied from any of them, whatever its license. Programs listed as references run as separate programs to cross-check henkan's output.

Where a program's source code was read, it was read only by the writers of henkan's behavior specifications. Those writers write no henkan code for the areas they read. The code for each area is written from the specifications, from public format documents, and from what reference programs produce when run, by contributors who never read the source for that area.
