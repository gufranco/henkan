# Notice

henkan is written from public format descriptions and from studying the programs below. They were read to learn what each format holds and what each tool does; no code, text, test, or data table was copied from any of them, whatever its license. Programs listed as references run as separate programs to cross-check henkan's output.

| Area | Source | License | How it was used |
|:--|:--|:--|:--|
| Feature set | [Game Format Converter](https://github.com/Mr-Shizzy/Game-Format-Converter), formerly CHD Manager, by Mr-Shizzy, including its issues, pull requests and forks | GPL-3.0-or-later | Features and behavior read from its documentation, history and command line; nothing read into the code; runs as a separate program to cross-check results |
| Feature set | [NKit](https://github.com/Nanook/NKit) by Nanook, including NKDS and OGMR | MIT | Features and the NKDS layout read from its documentation; its `nkit` and `nkds` programs run as references |
| Feature set | NKit 1.4 as attached to [Swiss](https://github.com/emukidid/swiss-gc) releases | MIT; Swiss is GPL-2.0 | Configuration keys and folder layout read; its data files are supplied by the person, never shipped |
| CHD | [chdman](https://github.com/mamedev/mame) from MAME | GPL-2.0-or-later | Runs as a separate program to create, read and verify CHD files |
